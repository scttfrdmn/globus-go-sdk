# Globus Go SDK v0.8.0 Release

## Overview

The v0.8.0 release of the Globus Go SDK introduces significant improvements to the client initialization pattern, error handling, and rate limiting mechanisms. This release also fixes numerous disabled tests and enhances the overall reliability of the SDK.

## Major Features

### Client Initialization Pattern

The v0.8.0 release introduces a consistent options pattern for client initialization across all services, providing a more flexible and extensible API:

```go
// Before (pre-v0.8.0)
client := transfer.NewClient(accessToken)

// After (v0.8.0+)
client, err := transfer.NewClient(
    transfer.WithAuthorizer(authorizers.NewStaticTokenAuthorizer(accessToken)),
    transfer.WithHTTPDebugging(true),
    transfer.WithBaseURL("https://custom-transfer.example.com/v0.10/"),
)
if err != nil {
    // Handle error
}
```

### Error Handling and Rate Limiting

This release introduces robust error handling and rate limiting strategies:

```go
// Using RetryWithBackoff for operations that might be affected by rate limiting
err := ratelimit.RetryWithBackoff(
    ctx,
    func(ctx context.Context) error {
        return client.Mkdir(ctx, endpointID, dirPath)
    },
    ratelimit.DefaultBackoff(),
    transfer.IsRetryableTransferError,
)

// Checking specific error types
if transfer.IsRateLimitExceeded(err) {
    log.Printf("Rate limit exceeded: %v", err)
} else if transfer.IsPermissionDenied(err) {
    log.Printf("Permission denied: %v", err)
}
```

### Authorization Improvements

Enhanced authorization mechanism with support for different types of authorizers:

```go
// Static token authorizer
client, err := transfer.NewClient(
    transfer.WithAuthorizer(authorizers.NewStaticTokenAuthorizer(accessToken)),
)

// Client credentials authorizer
authClient, err := auth.NewClient(
    auth.WithClientID(clientID),
    auth.WithClientSecret(clientSecret),
)
authorizer := authClient.CreateClientCredentialsAuthorizer(scopes...)
client, err := transfer.NewClient(
    transfer.WithAuthorizer(authorizer),
)

// Refreshable token authorizer
client, err := transfer.NewClient(
    transfer.WithAuthorizer(authorizers.NewRefreshableTokenAuthorizer(
        accessToken, refreshToken, expiresIn, refreshFunc,
    )),
)
```

Fixed numerous disabled tests and enhanced test infrastructure:

- Added robust error handling with retry mechanisms
- Improved resource cleanup in tests
- Enhanced diagnostic logging
- Added better mock server setup for unit tests

## Breaking Changes

The following breaking changes have been introduced in v0.8.0:

1. **Client Initialization**: All service clients now use the options pattern for initialization. Direct constructor calls with tokens (e.g., `NewClient(token)`) are no longer supported.

2. **Error Handling**: Some error types and error checking functions have been renamed or reorganized for consistency.

3. **Package Structure**: Some internal packages have been reorganized for better architecture.

## Upgrading

To upgrade to v0.8.0, follow these steps:

1. Update your import paths to use the latest version:
   ```go
   import "github.com/scttfrdmn/globus-go-sdk/pkg/services/auth"
   ```

2. Update client initialization to use the new options pattern (see the [Migration Guide](../V0.8.0_MIGRATION_GUIDE.md) for details).

3. Update error handling to use the new retry mechanisms and error type checkers.

4. Run tests to ensure everything works as expected.
