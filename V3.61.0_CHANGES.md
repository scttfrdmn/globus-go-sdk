# v3.61.0 Changes - Test Alignment & Python SDK Synchronization

**Release Date:** October 2, 2025
**Status:** ✅ Completed - Ready for Testing

## Overview

This release aligns the Go SDK with Python SDK v3.61.0 patterns and resolves test artifacts that were incorrectly documented as "incomplete work." No SDK functionality was missing - only tests needed updates.

## Key Findings

After thorough analysis of the upstream Globus Python SDK:

| Item | Status | Resolution |
|------|--------|------------|
| `RecursiveTransfer()` | ✅ Already Implemented | Fixed tests to use existing `SubmitRecursiveTransfer()` |
| `SubmitTextFileCreation()` | ❌ Never Existed | Removed test references, documented proper file operations |
| Activation Methods | 🚫 Deprecated in Python SDK v3.61.0 | Removed tests, documented auto-activation |
| CLI Transfer Commands | 📝 Deferred to v4.0.0 | Added deprecation notices |

## Changes Made

### 1. Transfer Integration Tests (`pkg/services/transfer/integration_test.go`)

#### Recursive Transfer Test Fixed
**Before:**
```go
t.Skip("Skipping recursive transfer test - RecursiveTransfer method not yet implemented")
// TODO: Uncomment when RecursiveTransfer is implemented
```

**After:**
```go
// Uses existing SubmitRecursiveTransfer() method
result, err := client.SubmitRecursiveTransfer(

    options,
```

**Files Modified:**
- `pkg/services/transfer/integration_test.go:675-877`

#### Activation Tests Removed
**Before:**
```go
t.Skip("Skipping activation requirements test - GetActivationRequirements method not yet implemented")
// TODO: Uncomment when GetActivationRequirements is implemented
// TODO: Uncomment when ActivateEndpoint is implemented
// TODO: Uncomment when ActivationProfile field is implemented
```

**After:**
```go
// DEPRECATED: Endpoint activation methods were deprecated in Python SDK v3.61.0
// due to Globus Connect Server v4 end-of-life. Modern endpoints (v5+) use
// auto-activation with properly scoped tokens.
t.Skip("Endpoint activation methods deprecated - modern endpoints use auto-activation with scoped tokens")
```

**Rationale:**
- Python SDK v3.61.0 deprecated all activation methods
- Globus Connect Server v4 reached end-of-life
- Modern endpoints auto-activate with proper transfer.api.globus.org scope
- See: `client.go:290-293` for existing deprecation note

**Files Modified:**
- `pkg/services/transfer/integration_test.go:907-919`

### 2. Resumable Transfer Tests (`pkg/services/transfer/resumable_integration_test.go`)

#### File Creation Test Artifacts Removed
**Before:**
```go
t.Skip("Skipping resumable transfer test - SubmitTextFileCreation method not yet implemented")
// TODO: Implement SubmitTextFileCreation method
```

**After:**
```go
// NOTE: File creation via API is not implemented in the SDK.
// In real usage, files should already exist on the endpoint or be created
// through other means (e.g., Globus Connect Personal, direct filesystem access).
if os.Getenv("ENABLE_RESUMABLE_TRANSFER_TEST") == "" {
    t.Skip("Skipping resumable transfer test - set ENABLE_RESUMABLE_TRANSFER_TEST=1 to enable")
}
```

**Rationale:**
- `SubmitTextFileCreation()` doesn't exist in Python SDK
- File operations are performed via:
  - Globus Connect Personal/Server (filesystem)
  - Transfer operations (copy/move)
  - External tools (GridFTP, SCP, etc.)
- Tests now check for existing files, skip if not present

**Files Modified:**
- `pkg/services/transfer/resumable_integration_test.go:79-238`
- `pkg/services/transfer/resumable_integration_test.go:391-533`

### 3. CLI Transfer Commands (`cmd/globus-cli/transfer/transfer.go`)

#### Added Deprecation Notices
**Before:**
```go
func ListCommand(args []string) error {
    return fmt.Errorf("LIST: Not implemented in this version")
}
```

**After:**
```go
// Deprecated: CLI transfer commands will be fully implemented in v4.0.0.
// For now, use the SDK library directly in your code.
func ListCommand(args []string) error {
    return fmt.Errorf("LIST command not implemented - use the transfer SDK package directly")
}
```

**Affected Functions:**
- `ListCommand()`
- `TransferCommand()`
- `StatusCommand()`

**Decision:** Defer CLI implementation to v4.0.0 when we have the new `GlobusApp` architecture

**Files Modified:**
- `cmd/globus-cli/transfer/transfer.go:9-28`

### 4. Compute Client Deprecation Notice (`pkg/services/compute/client.go`)

#### Added Python SDK v3.61.0 Alignment Note
**Added:**
```go
// NOTE: As of Python SDK v3.61.0, the ComputeClient alias is deprecated
// in favor of explicit version usage (ComputeClientV2, ComputeClientV3).
// This Go SDK uses v2 by default. In v4.0.0 of this SDK, we may introduce
// explicit versioning or require version specification.
```

**Files Modified:**
- `pkg/services/compute/client.go:28-35`
