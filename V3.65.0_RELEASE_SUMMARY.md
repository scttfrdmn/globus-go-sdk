## New Features

### 1. Groups Service Enhancements (v3.62.0-v3.65.0)

#### GetMyGroups with Status Filtering (v3.65.0)
**File:** `pkg/services/groups/client.go`

New convenience method for retrieving user's groups with optional status filtering:

```go
// Get all my groups
groups, err := client.GetMyGroups(ctx, nil)

// Get only active groups
groups, err := client.GetMyGroups(ctx, []string{"active"})

// Get active and pending groups
groups, err := client.GetMyGroups(ctx, []string{"active", "pending"})
```

**Implementation Details:**
- Added `Statuses []string` field to `ListGroupsOptions`
- Created `GetMyGroups()` convenience method
- Updated both `ListGroups()` and `ListGroupsV2()` to support statuses parameter

#### Batch Membership Operations (v3.65.0)
**File:** `pkg/services/groups/batch.go` (new)

New batch operations for efficient role management:

```go
// Single role change
err := client.ChangeRole(ctx, groupID, identityID, roleID)

// Batch role changes
changes := []groups.RoleChange{
    {GroupID: "group1", IdentityID: "user1", RoleID: "admin"},
    {GroupID: "group2", IdentityID: "user1", RoleID: "member"},
}
result, err := client.ChangeRoles(ctx, changes)

// Fluent API for batch operations
result, err := client.NewBatchMembershipActions().
    ChangeRole("group1", "user1", "admin").
    ChangeRole("group2", "user2", "member").
    Execute(ctx)
```

**New Types:**
- `RoleChange` - Represents a role change request
- `BatchRoleChangeRequest` - Batch request structure
- `BatchRoleChangeResult` - Aggregated results
- `BatchMembershipActions` - Fluent API builder

#### Subscription Management (v3.62.0-v3.63.0)
**File:** `pkg/services/groups/subscription.go` (new)

Enterprise-focused subscription association management:

```go
// Set subscription for a group
err := client.SetSubscriptionAdminVerified(ctx, groupID, subscriptionID)

// Get subscription
subscriptionID, err := client.GetSubscription(ctx, groupID)

// Remove subscription
err := client.RemoveSubscription(ctx, groupID)
```

**Version History:**
- v3.62.0: Originally added as `set_subscription_admin_verified_id`
- v3.63.0: Renamed to `SetSubscriptionAdminVerified` (current)

### 3. Flows Service Enhancement (v3.65.0)

#### FlowTimer Payload Class
**File:** `pkg/services/flows/timer.go` (new)

Structured integration with Globus Timers service for scheduled flow execution:

```go
// Create a flow timer with cron schedule
schedule := flows.NewCronSchedule("0 0 * * *", "America/New_York") // Daily at midnight EST
timer := flows.NewFlowTimer(
    "Daily Data Processing",
    flowID,
    map[string]interface{}{"dataset": "production"},
    schedule,
)

// Add optional configuration
timer.WithCallbackURL("https://myapp.com/callback").
      WithRunManagers([]string{managerID})

// Validate before submission
if err := timer.Validate(); err != nil {
    log.Fatal(err)
}
```

**Schedule Types:**
```go
// Cron schedule (time-based)
schedule := flows.NewCronSchedule("0 0 * * *", "America/New_York")

// Interval schedule (duration-based)
schedule := flows.NewIntervalSchedule("PT1H") // Every hour

// One-time schedule
schedule := flows.NewOnceSchedule(time.Date(2025, 1, 1, 0, 0, 0, 0, time.UTC))

// With time bounds
schedule.WithStartTime(startTime).WithEndTime(endTime)
```

**New Types:**
- `FlowTimer` - Complete timer payload structure
- `TimerSchedule` - Schedule definition with type, value, timezone
- `ErrInvalidFlowTimer` - Validation error type

**Features:**
- Fluent API for timer construction
- Multiple schedule types (cron, interval, once)
- Timezone support for cron schedules
- Start/end time bounds
- Run managers and monitors
- Built-in validation

**Groups - Status Filtering:**

// Before v3.65.0 - get all groups
groups, err := client.ListGroups(ctx, &groups.ListGroupsOptions{MyGroups: true})

// After v3.65.0 - filter by status
groups, err := client.GetMyGroups(ctx, []string{"active"})

**Groups - Batch Operations:**
```go
// Before v3.65.0 - sequential role changes
for _, change := range changes {
    err := updateMemberRole(ctx, change.GroupID, change.IdentityID, change.RoleID)
    // Handle errors individually
}

// After v3.65.0 - batch with aggregated results
result, err := client.ChangeRoles(ctx, changes)
for _, r := range result.Results {
    if !r.Success {
        log.Printf("Failed to change role: %s", r.Error)
    }
}
```

// New in v3.65.0 - structured timer creation
timer := flows.NewFlowTimer(
